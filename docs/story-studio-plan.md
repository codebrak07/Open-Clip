# Story Studio - Architectural Plan & Implementation Specification

> **Module**: Story Studio (`OpenClip AI`)  
> **Repository**: [github.com/codebrak07/Open-Clip](https://github.com/codebrak07/Open-Clip)  
> **Target Platform**: macOS (Apple Silicon M4) / Linux  
> **Status**: Planning & Specification Phase  

---

## 1. Executive Summary & Goal

Story Studio is an autonomous generative module inside OpenClip that transforms a single-line concept into a fully produced, 9:16 animated Roblox-style video with character voiceovers, word-level animations, sound effects mixing, dynamic burnt-in captions, and broadcast-ready export.

All creative decisions are generated by AI (Groq LPU and NVIDIA Cloud APIs) through a dual-pass writer-critic system. All video rendering is executed deterministically by code (Three.js within headless Chromium via Playwright piped directly into hardware-accelerated FFmpeg).

### Core Invariants:
1. **Deterministic Rendering**: Given the identical storyboard JSON and integer random seed, the rendering pipeline produces bit-exact, frame-consistent outputs.
2. **Reuse Existing Abstractions**: Integrates seamlessly with OpenClip's `RuntimeRegistry`, `WorkflowEngine`, `JobScheduler`, `VersionedArtifactStore`, `FFmpegService`, and caption pipelines.
3. **Closed Vocabulary**: Storyboard generation uses strict, validated catalog tokens (`assets/story/catalog.json`). Hallucinated or unknown IDs are rejected and repaired via Zod schema enforcement.
4. **Hard Constraints**: Groq Orpheus TTS strictly enforces a <= 200-character request limit with sentence-boundary chunking and direction preservation.
5. **Zero Temp-Frame Bloat**: Parallel Chromium pages pipe raw RGBA buffers directly into FFmpeg `stdin` using Apple Silicon `h264_videotoolbox` (fallback `libx264`).

## 3. Pipeline Stages & Content Hash Caching Strategy

Every pipeline stage is declared as a `WorkflowTask` within `WorkflowEngine`. Intermediate outputs are fingerprinted via SHA-256 and stored in `VersionedArtifactStore`:

1. **Idea & Config Fingerprint**:
   `hash = SHA256(idea + durationSec + tone + characterCount + seed)`
2. **Script Stage (`ScriptStage`)**:
   - Checks `VersionedArtifactStore.load(jobId, 'script')`. If hash matches, reuses cached script.
   - Pass A (Writer): Generates structured narrative beats with 2-second hook, rule-of-three, twist, and button gag.
   - Pass B (Critic): Critic LLM (secondary provider) reviews retention velocity, punchiness, and character voice, returning refined script beats.
3. **Storyboard Stage (`StoryboardStage`)**:
   - Maps script beats into strict JSON conforming to `StorySchema` against `assets/story/catalog.json`.
   - Zod validation. If invalid, sends error messages to an auto-repair prompt (up to 3 retries).
4. **Voice Synthesis Stage (`VoiceStage`)**:
   - Resolves voices per character from catalog.
   - Chunks dialogue lines at sentence/clause boundaries (`.`, `!`, `?`, `;`, `,`) to <= 200 characters including vocal direction tags.
   - Synthesizes WAV audio via Groq Orpheus (`canopylabs/orpheus-v1-english`).
   - Caches audio chunks by `SHA256(text + voice + directions)`.
5. **Word Alignment Stage (`AlignmentStage`)**:
   - Transcribes generated audio via Groq Whisper (`whisper-large-v3-turbo` with `timestamp_granularities[]=word`).
   - Anchors every beat, camera cut, action, expression, and SFX cue to word index, then maps to exact seconds.
6. **SFX Planning & Mix Stage (`SfxStage`)**:
   - Picks audio cues from `assets/sfx/index.json`.
   - Synthesizes any missing procedural SFX cues.
   - Mixes voiceover, SFX, and optional background ambience using FFmpeg filtergraph: sidechain ducking (-12 dB under dialogue), peak limiter (-6 dBFS), and target loudness (-14 LUFS).
7. **Render Stage (`RenderStage`)**:
   - Launches headless Chromium pool with Three.js `BlockWorld`.
   - Renders frames in parallel across `N` workers (`cores / 2`).
   - Streams raw frames into FFmpeg using `h264_videotoolbox` on Apple Silicon (or `libx264`).
8. **Captions & Master Export (`ExportStage`)**:
   - Burns dynamic `"story_pop"` word-synced subtitles in the top third of the frame.
   - Exports master 9:16 MP4 alongside sidecar artifacts (`.storyboard.json`, `.words.json`, `.sfx.json`, `.report.json`).

## 4. Provider Abstractions & Dynamic Model Resolution

### Provider Contracts
Located in `backend/src/core/contracts/index.ts`:

```typescript
export interface ScriptLLMProvider extends BaseProvider {
  generateScript(prompt: string, options: ScriptGenerationOptions): Promise<string>;
  critiqueScript(script: string, options: ScriptGenerationOptions): Promise<string>;
}

export interface SpeechSynthesisProvider extends BaseProvider {
  synthesizeSpeech(chunk: SpeechSynthesisChunk): Promise<Buffer>;
}

export interface ImageGenProvider extends BaseProvider {
  generateBackdrop(prompt: string, options?: ImageGenOptions): Promise<Buffer>;
}
```

### Dynamic Model Resolution
At startup or on demand, `StoryStudioService` queries provider endpoints:
- Groq: `GET https://api.groq.com/openai/v1/models`
- NVIDIA: `GET https://integrate.api.nvidia.com/v1/models`

Candidate ranking:
- **Groq Script Models**: `['gpt-oss-120b', 'llama-3.3-70b-versatile', 'llama-3.1-70b-versatile', 'llama-3.2-3b-preview']`
- **NVIDIA Script Models**: `['meta/llama-3.3-70b-instruct', 'nvidia/llama-3.1-nemotron-70b-instruct', 'meta/llama-3.1-70b-instruct', 'mistralai/mistral-large-2-instruct']`
- Fallback chain: Primary provider configured -> secondary fallback provider -> exponential backoff with jitter -> offline mock fallback for tests.

## 6. Procedural SFX & Sidechain Ducking Mixer

- **Procedural Synthesizer**: Pure deterministic DSP implemented in TypeScript generating 16-bit 44.1kHz WAV:
  - `whoosh`: Bandpass exponential frequency sweep (300Hz -> 3500Hz) with sine window.
  - `poof`: White noise burst + high-pass filter decaying in 120ms.
  - `boom`: Pitch-dropping sine thump (90Hz -> 35Hz) + noise transient with tanh saturation.
  - `riser`: Sawtooth + noise ascending pitch sweep with quadratic amplitude ramp.
  - `impact`: Low sine thud (65Hz) + initial transient burst.
  - `ice_crack`: High-frequency multi-tap impulses with random jitter.
  - `pop`: Fast sine blip (950Hz -> 350Hz) in 50ms.
  - `bonk`: Dual harmonic resonant chime (440Hz + 880Hz) with fast exponential damping.
  - `sparkle`: Bell chime cluster with harmonic bell decay.
  - `record_scratch`: Modulated noise + reverse pitch glide.
  - `footsteps`: Periodic low-frequency thumps with slight pitch randomization.
  - `wind_loop`: Slow bandpass-modulated white noise loop.
  - `room_tone_loop`: Low-frequency 60Hz hum + gentle white noise bed.
- **Mixer**:
  - Compiles an audio mix graph in FFmpeg.
  - Voiceover tracks are routed as primary.
  - SFX and background audio duck by 12 dB when voice is active.
  - Global audio limiter ensures peak <= -6 dBFS and loudness normalized to -14 LUFS (`loudnorm`).

## 7. BlockWorld Three.js / Playwright Parallel Renderer

- **Headless Worker Architecture**:
  - Headless Chromium controlled via Playwright.
  - Browser page loads local standalone bundle (`renderer.html`) containing Three.js and the BlockWorld engine.
  - Seeded PRNG replaces `Math.random` to guarantee identical vertex positions, particle paths, and easing trajectories.
  - `window.renderAt(timeSeconds, width, height)` captures WebGL frames.
- **Avatars**:
  - Modular Box-geometry humanoid (Head, Torso, Arms, Legs).
  - Canvas-based 2D dynamic facial expression texture updated per frame.
  - Mouth flap triggered by active Whisper word timestamp bounds.
- **Shots & Animation**:
  - Catmull-Rom spline camera moves with cubic easing.
  - Procedural skeleton joint rotations with ease-in-out interpolation.
- **Pipeline Performance**:
  - Total frame count = `durationSec * 30`.
  - Distributes frame chunks `[startFrame, endFrame]` across worker browser pages.
  - Pipes RGBA frame streams directly into FFmpeg `stdin`.
  - Encodes with Apple Silicon `h264_videotoolbox` (or `libx264`).

## 9. Risks & Mitigations

| Risk | Impact | Mitigation Strategy |
| :--- | :--- | :--- |
| **Groq Orpheus 200-char limit** | API rejected (400) if text exceeds 200 characters | Strict sentence/clause chunker splits on punctuation (`.`, `!`, `?`, `;`, `,`); verifies `< 200` chars before dispatching request. |
| **LLM Hallucinations** | Unknown props, shots, or character assets break renderer | Zod closed-vocabulary validator strictly rejects non-catalog IDs and triggers 3-stage LLM auto-repair prompt. |
| **Three.js Playwright Render Latency** | Missing the <= 3 min per 60s video performance target | Parallel Chromium instances (`cores / 2`); direct RGBA piping to FFmpeg stdin (no intermediate PNG files on disk); hardware `h264_videotoolbox` encoder. |
| **NVIDIA API Rate Limits / Cold Starts** | Stalled script or critic generation | Dynamic model detection with fallback to Groq LPU, exponential retry backoff, and local mock fallback during unit testing. |
| **Audio Desynchronization** | Lip-flap, actions, or SFX drifting from voice | Whisper word-level alignment resolves every action, cut, and SFX cue to absolute seconds anchored to actual spoken words. |

## 10. Benchmark & Quality Plan

- **Environment**: MacBook Pro (Apple Silicon M4).
- **Target Performance**:
  - Full 60-second 1080x1920 @ 30fps video renders in `<= 180 seconds` (3 minutes), excluding external cloud API latency.
  - Draft mode 540x960 @ 24fps renders in `<= 45 seconds`.
- **Metrics Collected**:
  - TTFT (Time to First Token) for Writer & Critic passes.
  - Voice synthesis throughput (characters / second).
  - Whisper alignment duration.
  - Renderer frames per second (fps) and render latency (ms / frame).
  - Audio mixing & FFmpeg export latency.
  - Frame hash consistency across seeds.
- **Reporting**:
  - Benchmark metrics documented in `docs/story-studio-report.md`.
  - Status clearly documented as *working*, *stubbed*, or *measured*.

## 11. Milestone Roadmap

- **Milestone 3 (M3)**: BlockWorld Three.js deterministic renderer in headless Chromium with avatars, expressions, camera motions, and parallel frame-pipe export.
- **Milestone 4 (M4)**: `"story_pop"` word-synced burnt-in captions, final 9:16 MP4 export with sidecars, and M4 Apple Silicon performance benchmark pass.
- **Milestone 5 (M5)**: REST API routes (`/api/v1/story/*`), frontend "Story Studio" workspace, end-to-end integration verification, and documentation updates.
